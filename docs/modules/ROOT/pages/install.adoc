= Install

== Runtime baseline

Current repository baseline:

* PHP `^8.4`
* Symfony `^8.1`
* Doctrine ORM `^3.3`

== Package-oriented setup surfaces

* `composer.json`
* `config/component/services.yaml`
* `config/component/routes.yaml`
* `config/component/doctrine.yaml`
* `phpunit.xml.dist`
* `tests/Application/`
* `phpstan.neon`

== Notes

This repository supports both reusable-bundle and standalone Symfony execution.
Host applications consume `App\\Attaching\\AttachingBundle` and the component exports under `config/component/`.
The repository-local standalone runtime uses `app/`, `bin/console`, `config/bundles.php`, and the root `config/` tree for development and operational verification.
Package verification also uses the embedded test application under `tests/Application/`.
